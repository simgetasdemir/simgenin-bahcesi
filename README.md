# Simge'nin Bahçesi

Eşleştir-3 bulmaca ile bahçe yenilemeyi birleştiren tarayıcı oyunu.

Simge, anneannesi Nevin Nine'nin Ege köyündeki bakımsız bahçesini Bahar Şenliği'ne hazırlıyor. Yanında huysuz ama iyi kalpli komşu Rıza Usta, çocukluk arkadaşı çiçekçi Ela ve ninenin kedisi Fıstık var.

## Oynanış

- Aynı türden 3 ya da daha fazla şeker taşı (Çiçek, Yaprak, Damla, Limon, Üzüm) yan yana getir.
- 4'lü dizi çizgili taş, L ya da T şekli bomba, 5'li dizi gökkuşağı tohumu yapar. İki özel taşı birleştirmek daha büyük patlatır.
- Yabani otların üstünde taş patlatarak onları sök.
- Her bulmaca 1 yıldız kazandırır. Yıldızlarla bahçe işlerini yap, hikayeyi ilerlet.
- İlerleme tarayıcıda saklanır.
